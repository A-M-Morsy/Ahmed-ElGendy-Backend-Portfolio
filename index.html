06 / Engineering philosophy

How I approach the work

Clean, maintainable code

SOLID principles, a clear service layer, small focused classes and honest code reviews, so the next engineer can change the system with confidence.

Performance by design

Measure first, then fix. Indexing, eliminating N+1 queries, caching with Redis and moving slow work to queues keep response times steady under load.

Security and compliance

Validated input, least-privilege access, signed webhooks, identity management with Keycloak and audit-ready log tracking, plus regulatory work such as ZATCA.

Leadership and delivery

I mentor developers, set coding standards and work in Agile teams, turning requirements into releases through CI/CD and clear communication.
